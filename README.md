# 30 Inch Vertical Tracker — GitHub Pages Ready

## Upload to GitHub Pages
1. Create a **public** GitHub repository (for example `30inch-vertical-tracker`).
2. Upload **all files in this folder to the repository root** — do not upload this folder itself.
3. In **Settings → Pages**, choose **Deploy from a branch → main → /(root) → Save**.
4. Open the published URL in **Safari on iPhone**.
5. Tap **Share → Add to Home Screen → Add**.

The tracker stores workout data in the browser's local storage. Use **Export backup** before changing devices or clearing Safari data.
